我需要使用rust实现一个简单的启动器stools。暂不考虑插件功能，ui部分使用slint

更加细致的需求：
- 我没有苹果设备，不打算适配macOS，只需要支持linux和windows
- 我想做成fuzzel这样可以预设固定大小居中，我觉得这样就可以省事，不需要考虑变动的列表导致窗口大小变化
- linux考虑不内置快捷键呼出和后台托盘，我使用的平铺管理器可以指定快捷键运行命令
- windows需要快捷键呼出，所以需要托盘在后台运行捕捉快捷键
- linux按下esc直接退出
- windows按下esc隐藏，下次呼出时全选输入框的文本

### 二、 Fuzzel 风格的 Slint UI 实现

Fuzzel 风格的核心是：**无边框、固定尺寸居中、半透明暗色背景、细边框、等宽字体与命令提示符 `>`**。

在 Slint 中，我们定义一个固定大小的窗口，并暴露 `select_all_input()` 函数供 Windows 唤出时调用：

#### `ui/launcher.slint`
```slint
import { ListView } from "std-widgets.slint";

export struct AppItem {
    id: string,
    name: string,
    exec: string,
    icon: image,
}

export component LauncherWindow inherits Window {
    // 1. 固定尺寸，无边框
    width: 520px;
    height: 480px;
    no-frame: true;
    always-on-top: true;
    background: transparent;

    // 暴露给 Rust 的属性与回调
    in-out property <[AppItem]> items: [];
    in-out property <int> selected_index: 0;
    callback search_changed(string);
    callback item_executed(int);
    callback escape_pressed();

    // 供 Windows 端唤起时全选文本并聚焦
    public function prepare_show() {
        input.select-all();
        input.focus();
    }

    forward-focus: input;

    // 主容器：带圆角和高斯模糊感的深色半透明背景
    main_container := Rectangle {
        background: #1e1e2edd; // Catppuccin / 暗色半透明
        border-radius: 12px;
        border-width: 1.5px;
        border-color: #89b4fa88; // 柔和的高亮边框

        VerticalLayout {
            padding: 14px;
            spacing: 10px;

            // 顶部输入栏（> 提示符 + 输入框）
            HorizontalLayout {
                spacing: 8px;
                alignment: center;
                height: 38px;

                Text {
                    text: ">";
                    color: #89b4fa;
                    font-size: 18px;
                    font-weight: 700;
                    font-family: "JetBrains Mono", "Fira Code", monospace;
                    vertical-alignment: center;
                }

                input := TextInput {
                    font-size: 16px;
                    font-family: "JetBrains Mono", "Fira Code", monospace;
                    color: #cdd6f4;
                    vertical-alignment: center;
                    single-line: true;

                    edited => {
                        root.search_changed(self.text);
                    }

                    key-pressed(event) => {
                        if (event.text == Key.Escape) {
                            root.escape_pressed();
                            return accept;
                        }
                        if (event.text == Key.DownArrow) {
                            root.selected_index = Math.min(root.selected_index + 1, root.items.length - 1);
                            return accept;
                        }
                        if (event.text == Key.UpArrow) {
                            root.selected_index = Math.max(root.selected_index - 1, 0);
                            return accept;
                        }
                        if (event.text == Key.Return) {
                            root.item_executed(root.selected_index);
                            return accept;
                        }
                        return reject;
                    }
                }
            }

            // 结果列表
            list := ListView {
                for item[index] in root.items : Rectangle {
                    height: 36px;
                    border-radius: 6px;
                    background: root.selected_index == index ? #45475a99 : transparent;

                    HorizontalLayout {
                        padding-left: 8px;
                        padding-right: 8px;
                        spacing: 12px;

                        Image {
                            source: item.icon;
                            width: 20px;
                            height: 20px;
                            vertical-alignment: center;
                        }

                        Text {
                            text: item.name;
                            color: root.selected_index == index ? #ffffff : #bac2de;
                            font-size: 15px;
                            font-family: "JetBrains Mono", "Fira Code", monospace;
                            vertical-alignment: center;
                        }
                    }

                    TouchArea {
                        clicked => {
                            root.selected_index = index;
                            root.item_executed(index);
                        }
                    }
                }
            }
        }
    }
}
```

### 三、 跨平台详细开发计划

#### 阶段一：核心索引与搜索模块（共享层）
1. **应用扫描器（App Scanner）**：
   * **Linux**：扫描 `/usr/share/applications`、`~/.local/share/applications` 解析 `.desktop` 文件的 `Name`、`Exec`、`Icon`。使用 `linicon` 或标准主题路径加载图标。
   * **Windows**：扫描开始菜单目录下的 `.lnk` 文件，通过 Win32 API 提取关联图标并保存为内存 RGBA 传给 Slint。
2. **高速模糊匹配（Matcher）**：
   * 引入 `nucleo-matcher` + `pinyin`。
   * 对每个应用建立索引结构：`{ name: "网易云音乐", pinyin_full: "wangyiyunyinyue", pinyin_abbr: "wyyyy", exec: "..." }`。
   * 搜索时同时对名称、全拼、首字母打分并降序排序。
3. **Linux 冷启动加速策略（关键）**：
   * 因为 Linux 下是随调随起，全量扫描 `.desktop` 和解析图标若耗时 50ms 会有肉眼可见的延迟。
   * **方案**：使用 `bincode` / `rkyv` 将解析好的应用结构序列化缓存至 `~/.cache/mylauncher/apps.bin`。
   * 启动时优先 `mmap` 读取缓存（耗时 < 2ms），同时另起后台线程做增量校验。

---

#### 阶段二：Linux 平台接入（极速单次启动模式）
1. **窗口居中与平铺管理器规则**：
   * **（标准无边框 + WM 规则，推荐）**：
     * Slint 设置 `no-frame: true`。
     * 在 Hyprland 配置中加入：
       ```ini
       windowrulev2 = float, class:(mylauncher)
       windowrulev2 = center, class:(mylauncher)
       windowrulev2 = noanim, class:(mylauncher)
       ```
     * 在 Sway 中加入 `for_window [app_id="mylauncher"] floating enable, move position center`。
2. **退出逻辑**：
   * Slint 监听 `escape_pressed` 回调 -> 直接调用 `std::process::exit(0)`。
   * 回车选择项 -> 使用 `std::process::Command` 脱离父进程（`detached`）执行目标程序 -> 立即 `exit(0)`。

---

#### 阶段三：Windows 平台接入（常驻后台 + 托盘 + 全局热键模式）
1. **依赖库选型**：
   * 全局热键：`global-hotkey`（Tauri 生态）。
   * 托盘管理：`tray-icon` + `muda`（托盘菜单）。
2. **事件循环与显隐控制**：
   * 启动后初始化 Slint 窗口，但不直接调用 `run()` 独占，而是隐藏窗口：`window.hide()`。
   * 监听 `global-hotkey` 触发（例如 `Alt+Space`）：
     1. 调用 `window.show()`。
     2. Windows 原生 API 置顶激活：`SetForegroundWindow(hwnd)`。
     3. 调用 Slint 的 `window.invoke_prepare_show()` 实现**文本全选与焦点定位**。
3. **隐藏与交互**：
   * Slint 监听 `escape_pressed` 回调 -> 调用 `window.hide()`（不退出进程）。
   * 回车选择项 -> 启动目标应用 -> 调用 `window.hide()`。
   * 点击托盘菜单中的 "退出" -> 调用 `slint::quit_event_loop()` 正式结束。

### 四、 项目结构与 Cargo 配置参考

```
mylauncher/
├── Cargo.toml
├── build.rs              # 编译 Slint 文件
├── ui/
│   └── launcher.slint    # Fuzzel 风格 UI 定义
└── src/
    ├── main.rs           # 平台入口分发
    ├── core/
    │   ├── indexer.rs    # 应用扫描与缓存
    │   ├── matcher.rs    # nucleo + pinyin 匹配算法
    │   └── model.rs      # 数据模型
    ├── platform/
    │   ├── mod.rs
    │   ├── linux.rs      # Linux 单次执行流
    │   └── windows.rs    # Windows 托盘与后台热键流
```

#### `Cargo.toml`
```toml
[package]
name = "mylauncher"
version = "0.1.0"
edition = "2021"

[dependencies]
slint = "1.9"
nucleo-matcher = "0.3"
pinyin = "0.10"
open = "5.3"
serde = { version = "1.0", features = ["derive"] }
bincode = "1.3"

# Linux 专用依赖
[target.'cfg(target_os = "linux")'.dependencies]
# 如需解析桌面文件
freedesktop-desktop-entry = "0.5"

# Windows 专用依赖
[target.'cfg(windows)'.dependencies]
global-hotkey = "0.5"
tray-icon = "0.15"
muda = "0.14" # 托盘菜单
windows = { version = "0.58", features = ["Win32_UI_WindowsAndMessaging"] }

[build-dependencies]
slint-build = "1.9"
```
