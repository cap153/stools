我观察到的问题：
- 图标、字体对不齐影响美观
- 移动到最底部的选项后没有没有继续同步向下滚动

而且我想复刻fuzzel的德古拉主题：
```

text=f8f8f2ff
match=8be9fdff
selection-match=8be9fdff

selection-text=f8f8f2ff
```

### 一、 问题原因剖析

1. **图标与文字不对齐的原因**：
   * 像“微信”、“Apollo”这些没有提取到图标的应用，它们的文本直接顶到了最左边。
   * **根因**：Slint 的 `Image` 在没有图片源（即 `Image::default()`）时，其宽度会坍塌为 0。没有给图标预留**固定宽度的容器**，导致有图标和无图标的项目左边距不一致。
   * **输入框与 `>` 偏移**：`TextInput` 默认自带上下内边距，套在 `Rectangle` 里容易与前面的 `>` 提示符基线对不齐。

2. **列表无法跟随滚动的原因**：
   * Slint 原生的 `ListView` 是一个仅响应鼠标滚轮的容器，**修改 `selected_index` 变量并不会自动让 `ListView` 滚动可视区域**。
   * **解决方案**：改用 `Flickable` 容器，配合每一行固定的高度与间距，在 `key-pressed` 改变 `selected_index` 时，**动态计算并更新 `viewport-y`**，让选中的项永远保持在可视区域内。

3. **Dracula 主题配色映射**：
   根据你提供的 fuzzel 配置，准确转换成 Slint RGBA 颜色代码：
   * 背景色 `background`: `#282a36dd`
   * 边框色 `border`: `#bd93f9ff`（吸睛的紫色细边框）
   * 提示符 `>` 与高亮匹配 `match`: `#8be9fdff`（青色）
   * 选中背景 `selection`: `#44475add`（深灰紫）
   * 文字颜色 `text` / `selection-text`: `#f8f8f2ff`（象牙白）
   * 占位文字: `#6272a4ff`（Dracula Comment 灰紫色）

### 二、 优化后的完整 `ui/launcher.slint`

直接替换现有的 `.slint` 文件：

```slint
export struct AppItem {
    id: string,
    name: string,
    exec: string,
    icon: image,
}

export component LauncherWindow inherits Window {
    // 固定窗口尺寸，无系统边框，透明底层
    width: 580px;
    height: 480px;
    no-frame: true;
    always-on-top: true;
    background: transparent;
    default-font-family: "JetBrains Mono", "Fira Code", monospace;

    // --- 数据属性与回调 ---
    in-out property <[AppItem]> items: [];
    in-out property <int> selected_index: 0;
    in-out property <string> query: "";

    callback search_changed(string);
    callback item_executed(int);
    callback escape_pressed();

    // 行高与布局常量，用于精确滚动计算
    private property <length> item_height: 38px;
    private property <length> item_spacing: 4px;
    private property <length> row_total_height: item_height + item_spacing;
    private property <length> list_view_height: 390px;

    // 辅助函数：根据 selected_index 自动让可视区域滚动跟随
    function ensure_visible(idx: int) {
        // 当前选中条目的顶部与底部 Y 坐标
        item_top := idx * root.row_total_height;
        item_bottom := item_top + root.item_height;

        // 如果超出上方视口，向上滚动
        if (item_top < -flick.viewport-y) {
            flick.viewport-y = -item_top;
        }
        // 如果超出下方视口，向下滚动
        if (item_bottom > -flick.viewport-y + root.list_view_height) {
            flick.viewport-y = -(item_bottom - root.list_view_height);
        }
    }

    // 供 Windows 端唤起前聚焦并全选
    public function prepare_show() {
        input.select-all();
        input.focus();
        flick.viewport-y = 0px;
    }

    forward-focus: input;

    // --- 主面板（Dracula 主题） ---
    main_container := Rectangle {
        width: 100%;
        height: 100%;
        background: #282a36dd;       // background=282a36dd
        border-radius: 10px;
        border-width: 1.5px;
        border-color: #bd93f9;       // border=bd93f9ff (Dracula Purple)
        clip: true;

        VerticalLayout {
            padding: 14px;
            spacing: 8px;

            // 1. 输入栏：">" 提示符 + 输入框，基线绝对对齐
            HorizontalLayout {
                height: 36px;
                spacing: 10px;
                alignment: center;

                Text {
                    text: ">";
                    color: #8be9fd;          // match=8be9fdff (Dracula Cyan)
                    font-size: 18px;
                    font-weight: 700;
                    vertical-alignment: center;
                }

                Rectangle {
                    horizontal-stretch: 1;
                    background: transparent;

                    // 占位提示文字
                    if root.query == "" : Text {
                        x: 0px;
                        width: 100%;
                        height: 100%;
                        text: "Search applications...";
                        color: #6272a4;      // Dracula Comment Color
                        font-size: 15px;
                        vertical-alignment: center;
                    }

                    input := TextInput {
                        width: 100%;
                        height: 100%;
                        font-size: 15px;
                        color: #f8f8f2;      // text=f8f8f2ff
                        selection-background-color: #bd93f9;
                        selection-foreground-color: #282a36;
                        single-line: true;
                        vertical-alignment: center;

                        edited => {
                            root.query = self.text;
                            root.search_changed(self.text);
                            root.selected_index = 0;
                            flick.viewport-y = 0px; // 重新搜索时滚回顶部
                        }

                        key-pressed(event) => {
                            if event.text == Key.Escape {
                                root.escape_pressed();
                                return accept;
                            }
                            if event.text == Key.DownArrow {
                                if root.items.length > 0 {
                                    root.selected_index = Math.min(root.selected_index + 1, root.items.length - 1);
                                    root.ensure_visible(root.selected_index);
                                }
                                return accept;
                            }
                            if event.text == Key.UpArrow {
                                if root.items.length > 0 {
                                    root.selected_index = Math.max(root.selected_index - 1, 0);
                                    root.ensure_visible(root.selected_index);
                                }
                                return accept;
                            }
                            if event.text == Key.Return {
                                if root.items.length > 0 {
                                    root.item_executed(root.selected_index);
                                }
                                return accept;
                            }
                            return reject;
                        }
                    }
                }
            }

            // 2. 结果列表容器（基于 Flickable 精确控制滚动）
            flick := Flickable {
                height: root.list_view_height;
                viewport-height: root.items.length * root.row_total_height;

                for item[index] in root.items : Rectangle {
                    y: index * root.row_total_height;
                    width: flick.width;
                    height: root.item_height;
                    border-radius: 6px;
                    
                    // 选中状态背景：selection=44475add
                    background: root.selected_index == index ? #44475add : transparent;

                    HorizontalLayout {
                        padding-left: 8px;
                        padding-right: 8px;
                        spacing: 12px;
                        alignment: center;

                        // 💡 关键：为图标固定 24px 宽度的容器，即使没有图标文字也不会向左坍塌偏移
                        Rectangle {
                            width: 24px;
                            height: 24px;
                            background: transparent;

                            Image {
                                source: item.icon;
                                width: 100%;
                                height: 100%;
                                image-fit: contain;
                            }
                        }

                        // 文本展示
                        Text {
                            horizontal-stretch: 1;
                            text: item.name;
                            color: #f8f8f2;  // selection-text / text = f8f8f2ff
                            font-size: 14.5px;
                            vertical-alignment: center;
                            overflow: elide;
                        }
                    }

                    TouchArea {
                        clicked => {
                            root.selected_index = index;
                            root.item_executed(index);
                        }
                    }
                }
            }
        }
    }
}
```

### 三、 这次修改解决的关键点

1. **无论是否有图标，文字绝对左对齐**：
   * 给 `Image` 外部包裹了一个固定的 `Rectangle { width: 24px; height: 24px; }`。即使某些软件没有提取出图标，这个 24px 的占位框依然存在，保证**所有软件名称的起始 X 坐标完全一致**。

2. **完美的键盘滚动跟随（Scroll into View）**：
   * 将 `ListView` 升级为 `Flickable`。
   * 新增 `ensure_visible(index)` 函数：当按下 `DownArrow` / `UpArrow` 移动光标且超出顶部或底部视口时，会自动实时调整 `flick.viewport-y`，丝滑平移至可见区域。
   * 用户输入新关键字搜索时，会自动重置 `flick.viewport-y = 0px` 回到顶部。

3. **原生 Dracula 配色注入**：
   * 窗口边框呈现标准的紫色 `#bd93f9`；
   * `>` 提示符呈现醒目的青色 `#8be9fd`；
   * 选中的条目呈现灰紫色 `#44475add`；
   * 占位符呈现低对比度的经典注释色 `#6272a4`。


我的模型没有视觉能力不要强求，让我自己验证，我肉眼观察到依然存在的问题：
- 选项和输入框变成居中了，这不是我想要的
- 图标比文字要高一点的问题依然存在

移动到最底部的选项后已经可以向下滚动了。

---

### 一、 问题根因定位

1. **为什么全部变成“居中”了？**
   * 在 Slint 的 `HorizontalLayout` 中，**`alignment` 控制的是主轴（水平方向）**，而不是交叉轴（垂直方向）。
   * 代码中写了 `alignment: center`，直接导致 Slint 把 `>`、输入框、图标、文字**全部挤到了窗口的正中间**。

2. **为什么图标依然比文字“高一点”？**
   * 每一行的高度是 `38px`。文字 `Text` 的高度撑满了 `38px` 并在内部设置了 `vertical-alignment: center`（文字中心在 $Y = 19\text{px}$）。
   * 而图标的 `Rectangle` 限制了 `height: 24px`，在 `HorizontalLayout` 里因为没有垂直居中约束，**直接贴着每一行的顶部（$Y = 0\text{px}$）对齐**（图标中心在 $Y = 12\text{px}$）。
   * 这导致图标的中心比文字**硬生生高出了整整 7 个像素**。

---

### 二、 修复方案

我们做两处精准调整：
1. **移除 `HorizontalLayout` 上的 `alignment: center`**，恢复自然的**左对齐**。
2. **列表行改用精确的绝对坐标定位**：
   * 图标容器：固定在左侧 `x: 10px`，垂直方向用数学公式 `y: (parent.height - self.height) / 2` **绝对居中**。
   * 文字：固定从 `x: 42px` 起始，高度 `100%` 配合 `vertical-alignment: center` **绝对居中**。
   * 无论软件有没有图标，文字起始的 X 坐标永远严格固定在 `42px`，绝不会左右晃动；垂直方向两者中心线绝对重合。
